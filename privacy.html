Privacy policy

Last updated: October 27, 2026

Atlas is a personal assistant application created and operated by Yarin Cohen for his own private use. It has a single user: its owner. It is not offered to the public.

What Atlas accesses

  • Google Calendar: to read the owner's events and, when he asks, create events.
  • Gmail: to search and read the owner's messages, summarize important ones and, only after his explicit confirmation, move messages to Trash.
  • Google Drive: only files that Atlas itself creates (a daily backup of its own data). Atlas cannot see any other Drive files.

How the data is used

Data is used only to answer the owner's own requests and to send him reminders and summaries. It is not sold, shared, or used for advertising, and it is not used to build profiles of anyone.

To generate answers, relevant text is sent to a large language model API (Google Gemini). No data is sent to any other third party.

Storage

Atlas runs on a private server controlled by the owner and reachable only through his private network. Its own data (tasks, reminders, settings) is stored on that server and backed up to the owner's Google Drive. Access tokens are stored only on that server.

Google API Services User Data Policy

Atlas's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
